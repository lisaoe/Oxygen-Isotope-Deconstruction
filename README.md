# Oxygen-Isotope-Deconstruction
This code aims to calculate the local signal of the bottom water stable oxygen istopope composition (reflecting salinity) found in benthic foraminifera (d18O). It applies a temperature and ice volume correction on the measured values, including a Generalized Least Squares (GLS) interpolation that brings the time series on the same grid. 
Please familiarize yourself with the steps and make sure all the input files and values are formatted appropriately and entered into the script.
